# Video frames

A frame is a transparent overlay recorded on top of a bugg: a festival border, team colours, confetti. People pick it in the recorder.

Make a folder (lowercase-with-dashes) with:

- `frame.png`: **1080 × 1920 px**, **transparent** wherever the video should show through, **600 KB or smaller**
- `frame.json`:

```json
{
  "name": "Afrobeats night",
  "author": { "name": "Your name", "github": "your-username" },
  "license": "CC-BY-4.0",
  "description": "Gold border with a little drum in the corner.",
  "file": "frame.png",
  "tags": ["music", "party"]
}
```

Keep the **middle clear**, and keep the **bottom 400 px and right 200 px light**, because the app's buttons and captions sit there. No logos, brands or text that could look like an ad.
